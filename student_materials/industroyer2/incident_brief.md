# 事件通報：OT-SERVER01 出現待釐清的 IEC-104 控制活動

## 通報摘要

在本次隔離的 Industroyer2-like 教學模擬中，OT-SERVER01 偵測到與
IEC-104 控制活動相關的紀錄。Server 端可觀測到目的服務使用 TCP/2404，
部分紀錄顯示來源為工程工作站所在的網段。

目前資訊不足以直接判定這是授權的 ENG 維護、由外部模擬端直接發起的
操作，或是經由 ENG01 Relay 轉送的操作。學生的任務不是猜測真實世界
攻擊者，而是使用可取得的 Lab 證據，保守地還原本次模擬中可證實的事件關係。

## 初始已知事項

- OT-SERVER01 是本 Lab 的控制服務端，會留下控制相關的 Server 紀錄。
- ENG01 是工程工作站；正常維護操作可能由它對 OT-SERVER01 發出
  IEC-104 通訊。
- Kali 是隔離 Lab 中的安全模擬端，用來產生可控、非破壞性的對照案例。
- SENSOR01 已收集並正規化多端資料，供教學助理依問題檢索。

## 待回答的調查問題

1. Server 看到工程工作站來源 IP 時，可以直接判定最初發起者嗎？
2. 正常 ENG 維護與經 ENG Relay 的操作，哪些觀測結果可能相似？
3. 需要比對哪些跨主機紀錄，才能判斷操作脈絡？
4. 若資料沒有記錄網路路徑、封包欄位或裝置回應，應如何描述這個證據缺口？

## 學習限制

本情境是安全、可逆的教學模擬，不代表真實 Industroyer2 事件重現。
不得將 Lab 中的來源 IP、控制項目、檔案或狀態值延伸為真實事件史實。
遇到沒有證據支持的問題，應明確標示為「證據不足」而不是補齊假設。
